# AI Media Flow

一个图片与视频生成工作台，用于把素材、提示词、生成任务和结果放在同一条流程里。案例内容不写死，任何项目都可以使用。腾讯云上传与签名使用官方 COS Node.js SDK。

## 本地运行

Windows 下安装 Node.js 22.9+ 后，双击项目根目录的 `start.bat` 即可同时启动前端页面和后端接口，并在服务就绪后自动打开浏览器。首次启动会安装依赖，需要网络。保留命令窗口，使用结束后按 `Ctrl+C` 停止服务。

首次部署先把 `.env.example` 复制为 `.env`，设置 `APP_ACCESS_PASSWORD`。登录后进入页面右上角“模型设置”，填写图片和视频接口配置。也可以使用以下命令启动：

```powershell
npm start
```

命令行首次启动前先运行 `npm ci`。`npm start`、`npm run dev` 和 `start.bat` 均读取项目根目录的 `.env`；修改服务端配置后需重启。

打开 `http://localhost:4173`。数据默认保存在 `data/state.json`。

## 服务器运行

服务器安装 Node.js 22.9+ 后，先运行 `npm ci --omit=dev`，再启动：

```bash
AI_FLOW_PORT=4173 AI_FLOW_DATA_DIR=/var/lib/ai-media-flow node --env-file-if-exists=.env server.js
```

也可以使用 Docker Compose 启动，无需在宿主机安装 Node.js。首次部署先将 `.env.example` 复制为 `.env`，填写 `APP_ACCESS_PASSWORD`，然后在项目根目录执行：

```bash
docker compose up -d --build
```

默认访问 `http://localhost:4173`。Compose 会读取 `.env` 中的访问密码、COS 等配置；`AI_FLOW_PORT` 控制宿主机端口，`AI_FLOW_DATA_DIR` 控制宿主机数据目录（默认 `./data`，相对路径以项目目录为基准）。容器内部固定使用端口 `4173` 和 `/app/data`，数据目录通过挂载持久化，已有本地数据可以继续使用。不要同时运行本地服务和容器来读写同一数据目录。

```bash
docker compose logs -f     # 查看日志
docker compose down        # 停止并移除容器，保留宿主机数据
docker compose up -d --build # 更新代码或 .env 后重新构建并启动
```

容器随 Docker 自动重启；手动停止后需再次执行启动命令。备份时保留整个数据目录，其中包含素材、模型配置及其加密密钥和登录会话。

也可以单独构建镜像：

```bash
docker build -t ai-media-flow .
docker run --rm --env-file .env -p 4173:4173 -v ai-media-flow-data:/app/data ai-media-flow
```

服务器部署需使用 HTTPS，并持久化数据目录。应用已内置访问密码保护；反向代理应正确传递 Host 和 X-Forwarded-Proto。

## 资源保留 7 天

上传素材从上传时间起、生成图片和视频从结果保存时间起，保留 **7×24 小时**。已有资源也按原时间计算；首次升级后，超过 7 天的资源会被清理。旧记录缺少有效时间时，从首次升级读取时开始计算。

- 到期删除图片 Base64、保存的外部链接、本地 MP4 和视频下载缓存；名称、提示词和任务历史保留。上传区、生成区及确认区显示“已删除 / 超过 7 天保留期”的占位。
- 过期资源不能预览、下载或用作图片、视频参考；当前草稿中的过期引用自动移除，后端也会拒绝旧页面或直接接口提交的过期素材 ID。已提交到上游的生成任务不会被自动取消或重复提交。
- 启动时清理，运行中每分钟检查；访问 API 时也检查到期状态。服务停机期间无法删除文件，恢复启动时补做清理。文件因权限或占用删除失败时，资源仍不可访问，后台记录错误并继续重试。
- 启用 COS 时，到期也会删除已登记的临时副本，需要 `DeleteObject` 权限；签名链接有效期不会超过资源剩余保留期。原有 2 天临时对象生命周期规则继续保留。升级前未登记的历史副本、存储桶旧版本仍由 COS 生命周期处理，实际删除时间取决于云端策略执行。
- 此规则管理本应用的数据目录和登记的 COS 临时副本，不会删除用户已下载到其他位置的文件，也不能控制 API 服务商自己的保存期限。重要资源请在 7 天内自行下载。

## 访问密码与 30 天登录

访问密码只从服务端 `.env`（或部署环境变量）读取，不通过网页设置查看或修改：

```dotenv
APP_ACCESS_PASSWORD=在此填写你的访问密码
```

密码不能为空；未配置时应用拒绝启动，不会以无密码模式公开工作区。修改配置后重启生效。API Key 的页面配置与访问密码分开管理。密码包含 `#` 或空格时请使用双引号包裹配置值。

- 登录后签发 30 天有效的 HttpOnly、SameSite=Lax Cookie，有效期从本次登录起算；刷新、浏览器关闭和服务器重启不会重新计算或提前结束有效期（浏览器主动清除 Cookie 除外）。
- 会话保存在数据目录的 `access-sessions.json`，登录校验密钥为 `access.key`。会话文件仅保存随机令牌的哈希与到期时间，不保存明文密码或原始 Cookie。备份、迁移或容器部署时保留整个数据目录；不要删除这两个文件。
- 页面右上角“退出登录”会撤销当前会话；修改访问密码并重启会撤销所有已有会话。每个登录设备独立记录，最多保留 100 个设备。
- 未登录时首页跳转登录页；项目数据、模型设置、图片及视频文件、下载与修改接口均返回未授权。请求来源校验限制跨站写操作；同一来源连续 10 次错误密码会暂时限制登录 15 分钟。
- `/api/kyy-assets/*` 的 GET/HEAD 供视频服务商抓取素材，继续验证原有的单文件限时签名，不要求网站 Cookie。无效、过期签名仍然拒绝访问；其余 API 不走此例外。
- 本地 HTTP 可以直接使用。服务器 HTTPS 部署建议设置 `APP_COOKIE_SECURE=true`，确保 Cookie 仅经 HTTPS 传输；未显式设置时会依据 TLS 或代理的 `X-Forwarded-Proto: https` 自动启用 Secure。本地 HTTP 不要设置为 true。

当前为单个共享访问密码，不提供多用户账号、角色或权限区分。服务进程退出不会撤销登录，但正在执行的模型任务仍需保持后端运行。

## 模型配置

登录后打开页面右上角“模型设置”，分别填写图片和视频服务的 **Base URL、模型名称和 API Key**，视频服务还需选择 **接口类型**，点击“保存配置”。

- 保存后新任务立即使用，无需重启服务；正在执行的任务保持启动时的配置。
- API Key 留空保留原值，输入新值替换；勾选“清除”可删除当前密钥并停用该服务的真实调用。
- 设置页用 `********` 提示密钥已配置，不回显已保存的 API Key；读取和保存配置的接口均不返回密钥明文。输入新密钥时隐藏字符，留空保留原值，勾选“清除”删除。API Key 不写入浏览器本地存储，后端以加密文件保存。
- “已配置”不代表接口连通性已验证；保存不会发起模型调用或产生生成费用。
- Base URL 使用 HTTPS，本机代理允许 HTTP；填写 API 根地址，不要添加具体的生成接口路径。
- 若已有环境变量配置，首次使用会读取它们；页面保存后以页面设置为准，清除密钥也不会自动恢复环境变量中的旧值。

配置加密保存在数据目录的 `settings.enc`，加密密钥为同目录的 `settings.key`。备份和迁移时保留这两个文件并保护整个数据目录的访问权限；二者同时泄露仍可解密。它们不进入项目数据或素材导出。

服务器部署时使用 HTTPS，并限制绕过 HTTPS 代理直接访问应用端口。所有获得访问密码的人共享同一个工作区和模型设置；当前应用没有多用户权限系统。

## 项目首页

打开网站根地址先进入项目首页，展示项目名称、备注、图片/视频数量、最近时间和正在生成的任务数。点击项目进入工作台，顶部“项目首页”或 FLOW 标志可返回列表；首页可创建新项目，创建后直接进入工作台。

首页初始化和任务轮询只返回记录及资源地址，不再通过 `/api/bootstrap` 重复传输全部 Base64 原图或任务中的图片副本。内嵌图片、音视频通过受登录保护的 `/api/media/:id` 按需读取，仍遵守 7 天保留期；原始数据保存方式不变，无需迁移，生成参考继续读取服务器原始内容。

工作台使用 `#/project/项目ID` 地址，刷新会保留当前项目，浏览器后退/前进也能切换首页与项目；根地址或 `#/` 始终显示首页。在当前标签页内往返首页或切换项目，会分别保留尚未提交的图片和视频输入草稿；刷新整个网页不会保存这些未提交草稿。后台任务继续运行，首页会更新项目任务数。

## 素材与视频工作台

工作台现在按“素材预处理区 → 素材确认区 → 视频生成区 → 视频确认区”固定排列。第一段按上传图、生成图分类展示，配一个统一生图输入区；第二、三段继续保持确认素材和生成视频的流程。旧项目、素材、生成结果、API 设置与 COS 配置继续使用。

- **预处理区**：固定分为“上传的素材”和“生成的素材”两栏，图片横向展示并支持滚动。随时 Ctrl+V、拖入或手动选择图片即可导入；生成结果自动加入第二栏。
- **再次生图**：将上传/生成素材拖入提示词上方的参考图区，或点击素材下方“添加参考”，最多 8 张，重复拖入不会重复添加。参考图区也支持直接拖入本地图片并上传。未添加参考图时为文字生图，添加后把实际图片提交给编辑接口。下方统一填写提示词、选择比例并生成；“清空参考”只清空生图参考，不影响确认区和视频素材。任务刷新不会清掉正在输入的提示词，当前页面内切换项目会分别保留草稿。
- **大图预览**：点击上传素材、生成素材、确认区或参考图区中的图片打开大图；按 Esc、右上角关闭按钮或点击背景关闭。图片点击只预览，不改变参考选择。参考图区右上角“×”仅取消本次引用，原始素材在 7 天保留期内仍保留。
- **画面比例**：使用图标卡片选择 1:1、3:4、4:3、9:16、16:9，分别提交 1024×1024、1152×1536、1536×1152、864×1536、1536×864。兼容服务商需要支持对应尺寸。
- **移除图片**：素材图片右上角的“×”只把图片从当前工作区移除并解除确认/选择，原图在 7 天保留期内保留，生成历史继续保留；“恢复移除的素材”可恢复显示。旧画布节点和布局数据仍保存在项目中，但当前页面不再使用画布或生图节点。
- **确认区**：只有点击“加入确认区”的图片才会进入视频生成候选。确认列表会按项目保存，刷新或重新打开项目后恢复；可以继续添加或取消。
- **视频生成区**：将确认区图片拖入视频提示词上方的参考图区，或点击确认图下方“用于视频”。参考缩略图支持大图预览，右上角 × 及“清空参考”仅取消本次视频引用，不删除已确认素材。重复拖入不会重复添加；首尾帧按添加顺序标注。填写视频提示词后，直接点击画幅比例、分辨率和素材模式选项；时长使用横向滑条与数字输入框双向同步，离开输入框时校正为接口范围内的整数。kyyReactApi 为 4–15 秒，其他兼容接口按现有 1–60 秒范围校验，实际支持范围仍以服务商为准。OpenAI Video（兼容接口）与 kyyReactApi 均支持最多 9 张参考图，或最多 2 张首尾帧（第一张为首帧、第二张为尾帧）；火山引擎当前适配仍限制 1 张。
- **异步生图**：任务提交并保存后，按钮立即恢复，可继续提交下一张，不等待上一张生成完成。“生成的素材”按任务显示排队/生成中的占位、提示词和提交时间；刷新网页会从后端恢复占位。完成后在相同排序位置替换为图片，失败会结束占位并提示原因，不自动重提付费任务。后端服务须保持运行，浏览器刷新与服务重启不是同一回事。
- **视频占位与刷新**：视频任务显示为固定 16:9 预览框的卡片，包含排队/生成状态、提示词摘要、时长和画幅。完成后在原卡片内展示视频。轮询仅更新变化的内容，各视频卡片按任务 ID 复用；新增或完成其他任务不会重新创建已有播放器。
- **视频确认区**：成功生成的真实视频默认加入（包括已有结果，演示占位不加入）。生成结果可手动“加入确认区”；确认区的“移除”只取消确认，原文件在 7 天保留期内保留，历史记录继续保留，刷新后不会自动回来。确认状态单独保存在结果记录中，不会被图片确认或项目布局保存覆盖。
- **视频下载**：点击每张视频卡片的“下载视频”逐个下载 MP4，不提供 ZIP 打包。远程 HTTPS MP4 会由服务端读取并缓存到数据目录 `video-downloads/`，浏览器不需要处理跨域；后续可复用缓存。本地视频直接读取原文件。单个视频上限 256 MB，前端使用浏览器内存准备下载。远程地址过期且尚无缓存时会提示失败，需要向服务商获取有效地址；不自动重提付费生成。
- **任务结果**：图片生成结果自动回到“生成的素材”栏；视频生成结果显示在视频生成区下方。任务记录保留失败、待核实和上游任务 ID。
- **拖入与粘贴**：任意页面拖入或 Ctrl+V 都会进入预处理区，提示词文字不会被图片粘贴打断。上传过程完成前，生成按钮会暂时等待。
- **兼容旧数据**：旧画布里的卡片位置不会被当成“已确认素材”；需要重新在预处理区点击“加入确认区”，避免历史草稿误进入视频任务。

界面不再要求选择镜头或反复打开生成弹窗；后台继续用现有镜头/任务记录保存生成历史。确认区继续使用项目 `canvas.workflow=confirmed-materials-v1` 和 `assetIds` 保存。旧布局和生图节点数据保留用于兼容，不会在新界面自动变成已选参考图。

图片编辑接口依据：[OpenAI 图片编辑 API](https://developers.openai.com/api/reference/resources/images/methods/edit)。兼容服务商必须支持该协议；不支持时明确报错，不会降级为无参考图的文字生成。

## 视频接口类型

未配置时，图片和视频的 Base URL 均默认为 `https://new.every-ai.cc/v1`；视频接口默认为 OpenAI Video（兼容接口），视频模型默认为 `doubao-seedance-2-0-mini-260615`。图片模型仍为 `gpt-image-2`。已保存的配置和环境变量优先于默认值；已有火山引擎配置需明确选择火山引擎官方类型。

| 接口类型 | Base URL 示例 | 模型示例 | 提交与查询 |
| --- | --- | --- | --- |
| 火山引擎官方（Ark） | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedance-2-0-260128` | `POST /contents/generations/tasks`、`GET /contents/generations/tasks/{id}` |
| OpenAI Video（兼容接口） | `https://new.every-ai.cc/v1` | `doubao-seedance-2-0-mini-260615` | `POST /videos`、`GET /videos/{id}`，必要时 `GET /videos/{id}/content` |
| kyyReactApi | `https://zcbservice.aizfw.cn/kyyReactApiServer` | `sd_2.0_special` | `POST /v2/model-center/tasks`、`GET /v2/model-center/tasks/{id}` |

- 三种类型复用视频配置中的 API Key、Base URL 和模型名称；不要将图片服务的 Key 当作视频服务的 Key。
- 切换类型不会覆盖原先输入的地址、模型或密钥，请一起检查。OpenAI Video 指的是协议格式，不代表 OpenAI 官方提供 Seedance 模型。
- OpenAI 类型通过 `/videos` 发送 JSON，保留 `seconds`、`size`。页面选择的多图/首尾帧按 New API 的 Seedance 扩展放入 `metadata.content`，每张图片包含 `image_url.url` 和 `role`（`reference_image`、`first_frame` 或 `last_frame`）；参考图与首尾帧不能混用。支持 PNG/JPEG/WebP Base64 图片和 URL，启用 COS 时复用临时素材中转。旧单图调用仍兼容 `input_reference.image_url`。该多图扩展需要服务商支持，不能视为所有 OpenAI 官方模型都支持多图。适配依据：[New API Seedance 源码](https://github.com/QuantumNous/new-api/blob/main/plugins/tasks/doubao/plugin.js)。
- 创建视频时可选择时长及画幅/尺寸，避免将图片分辨率直接传入视频接口。OpenAI 官方参考图尺寸需要与目标视频尺寸匹配，应用不自动裁切。
- kyyReactApi 通过 JSON 的 `url` 字段登记素材，再用 `assetDetail` 查询至 `ACTIVE`，最后以 `assetId://` 生成。在画布中选择素材库和已生成结果中的图片、视频、音频；右侧可切换首尾帧模式。也可填写已有 URL 或 assetId 覆盖参考图片。
- 点击“使用图片生成视频”后，可在右侧高级选项填写 URL 或素材 ID 覆盖当前参考图；无参考图时可以仅使用提示词。
- 未配置 Key 时仍为演示模式；已配置时遇到无效输入会明确报错，不再静默使用演示结果。
- 任务记录保存接口类型、模型及上游任务 ID；服务切换不影响已经开始的任务。无法确认的查询或超时标记为“待核实”，不自动重新提交付费请求。
- OpenAI 标准内容接口返回的 MP4 会保存到数据目录的 `videos/` 下，供浏览器播放。单文件保存上限为 256 MB。返回直接视频链接的兼容接口及其他类型目前保留该链接，请在有效期内下载；没有承诺所有远程链接永久可用。
- 接口已用本地模拟服务验证；实际账号权限、模型可用性和费用仍需真实账号联调。

### 本地素材如何交给 kyyReactApi

推荐管理员启用下面的 COS 中转；启用后无需为本机配置公网入口，页面也不再要求填写素材访问地址。未启用 COS 时仍可使用原有方式：

1. 在“模型设置 → 视频生成”填写“素材访问地址”：这是你自己指向本应用的 HTTPS 地址，**不是** kyyReactApi 的接口地址。
2. 配置域名和 HTTPS 反向代理，使外部能够访问本应用的 `/api/kyy-assets/*`。仅填一个域名不会自动创建网络通道；localhost、局域网地址无法被服务商读取。本次开发没有配置公网域名或隧道。
3. 生成时，后端把选中的本地素材转换为 1 小时有效的签名 URL，并提交素材接口。只有签名对应的文件可读取；过期、伪造签名均返回 403，支持 GET / HEAD / Range。
4. 素材审核失败时不提交视频生成任务。原始文件不被压缩或覆盖，也不上传到额外图床。已有公网 HTTPS 素材可直接引用，无需本地转发地址。

**公网仅开放签名素材路径，其他页面和 API 保持本机访问或登录保护。** 设置接口不回传已保存的 API Key；整个工作台仍需访问密码保护。签名本身是限时访问凭据，请勿分享任务中的素材 URL。

文件大小上限为图片 30 MB、视频 50 MB、音频 15 MB；时长、帧率、宽高和内容审核仍以服务商实际校验为准。模拟测试验证了素材回读、审核等待和任务参数，不等于真实服务已联网生成成功。

### 腾讯云 COS 临时中转（仅管理员配置）

在服务器或本机项目根目录的 `.env` 中填写，模板见 `.env.example`：

```dotenv
COS_ENABLED=true
COS_SECRET_ID=管理员的SecretId
COS_SECRET_KEY=管理员的SecretKey
COS_BUCKET=存储桶名称-APPID
COS_REGION=ap-guangzhou
```

`COS_REGION` 必须是桶的实际地域，例如广州 `ap-guangzhou`、北京 `ap-beijing`。默认 `COS_ENABLED=false`，不会连接腾讯云；启用但配置不完整会阻止启动并提示管理员补齐。改完重启应用。模型 API 仍在原来的网页设置中配置。

**配置隔离：** COS 配置不放进模型设置，也不允许网页 API 修改；网页仅收到是否启用中转和素材上传状态。桶、对象键及上传时间保存在服务端数据目录的 `cos-objects.json`，不通过 bootstrap 或导出返回；签名 URL 仅在后端与视频平台之间传递。`.env` 不进入 Docker 镜像。请用操作系统文件权限限制配置文件和数据目录仅部署管理员可读；这不是新增网站管理员账号系统。

**存储桶准备：** 推荐专用、私有读写、未开启版本控制的标准存储桶。保留 `image-video-flow/temp/` 目录给本应用，不能放永久文件。凭据需要目标桶的 `GetBucketLifecycle`、`PutBucketLifecycle` 权限，以及上述目录的 `PutObject`、`HeadObject`、`GetObject`、`DeleteObject` 权限。应用不会把桶改成公共读；无需配置 CDN，也不需要浏览器直传 CORS。

**403 排查：** `SignatureDoesNotMatch` 表示签名校验失败，先核对腾讯云 API 密钥管理中同一条记录的 SecretId / SecretKey，完整更新 `.env` 后重启；不要混用不同记录的密钥，增加桶权限不能修复签名错误。`InvalidAccessKeyId` 检查密钥 ID 是否正确有效；`RequestTimeTooSkewed` 或签名过期需同步系统时间。仅当错误为 `AccessDenied` 时，再根据提示检查读取生命周期的 `GetBucketLifecycle` 或写入生命周期的 `PutBucketLifecycle` 等权限及资源范围。应用仅显示固定的错误分类，不回传腾讯云原始请求、密钥和签名内容。

**自动清理：** 首次上传前，应用读取桶的生命周期配置，新增/修复名为 `ai-media-flow-temp-v1` 的规则，仅对 `image-video-flow/temp/` 下文件设置修改后 **2 天**删除，保留其他规则。后续上传/使用素材时重新检查；如果缺少生命周期权限或配置失败，不上传新文件，避免留下没有清理策略的副本。管理员不要同时在控制台或另一个实例修改生命周期配置，也不要给同一目录配置更短的删除或归档规则。

生命周期由腾讯云执行，应用退出或电脑关机不影响清理；它按天扫描，不保证恰好 48 小时删除。如果桶已开启版本控制，本规则还会在文件成为历史版本 **2 天后**删除历史数据，因此实际物理删除可能更晚，删除标记可能保留。若不需要版本控制，使用未开启版本控制的专用桶最直接。规则删除的是 COS 副本，不会删除应用素材库原图或视频平台已经导入的素材。

**日常行为：**

- 上传/粘贴本地素材后，先保存原图，再自动上传临时副本；真实 AI 图片结果也会自动中转。仅返回远程图片 URL 的生成接口会先下载原图到本地保存；要求 HTTPS 图片直链，重定向、内网地址、非图片及超过 30 MB 的结果会提示失败。
- 生成视频前，后端检查云端对象，签发 **24 小时**有效的访问链接。原有素材会在首次使用时补传，网页不需要手动复制 URL。
- 对象不存在，或上传已超过 12 小时时，使用原始文件上传一个新对象，保证新任务有充足的链接时间；旧对象仍由生命周期删除，避免中断仍在读取它的任务。服务重启后可继续复用记录。
- 云端上传失败不删除原图，也不把图片生成误报为失败；任务记录及所选素材详情显示提示，再次生成视频时重试。视频所需素材中转失败时，不提交付费视频任务。
- 手动填写的公网图片 URL 或 `assetId://` 继续直接使用。演示模式的占位图片不会自动上传。
- 删除本地素材不会立即删除 COS 副本，副本仍按生命周期到期清理，避免影响进行中的任务。

测试覆盖官方 SDK 的真实请求格式与本地模拟 COS/视频服务串联、云端文件删除后补传、失败保留原图、配置隔离；尚未使用真实腾讯云账号或真实视频服务联调。
